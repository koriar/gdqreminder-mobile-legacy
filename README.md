# GDQ Reminder Mobile App (Legacy)

This is a forked version of the GDQ Reminder App for Android. Originally created by ViMaSter. (https://github.com/ViMaSter/gdqreminder-mobile)

Modified by Koriar.

In January 2025, the original app became unusable on Android 10. A month later, GDQ closed the API that the pre-January version used.

This is a modified version of the last version that works on Android 10, but using the new GDQ API.

I've done absolutely zero Android development before this, so it is very sloppy. I just wanted to extend out me having to buy a new phone for another few years.
